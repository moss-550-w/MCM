## 问题一：最优物流方案与资源调度

### 1.1 模型概述

采用 **离散时间混合整数线性规划（DT-MILP）** 框架，以 10 个火箭发射基地与 3 个太空电梯港口为决策节点，在 50 年规划周期（2050–2100）内优化地月物资运输。

- **决策变量**: 各基地/港口在每期（季度/年）的发射/运输量、电梯建设 0-1 决策
- **目标函数**: 综合最小化 **时间 + 成本 + 环境碳排放**
- **核心约束**: 总物资需求 1 亿公吨、基地运力上限、电梯建设周期

### 1.2 关键假设

| 编号 | 假设内容 | 合理性说明 |
|------|----------|------------|
| 1 | 火箭单次载荷 100–150 公吨，取均值建模 | 载荷波动 ±10%，属于微小扰动，基础建模取均值可简化离散决策 |
| 2 | 电梯单港年运力 17.9 万公吨，建设周期 10 年 | 基于题目给定工程参数 |
| 3 | 运输决策以季度/年为离散时间步长 | 符合运力数据统计维度，降低变量维度 |
| 4 | 碳排放仅与火箭发射数量线性相关 | 分离运力补偿与环境影响的决策维度，聚焦核心优化目标 |

### 1.3 求解结果

| 指标 | 数值 |
|------|------|
| **电梯建设决策** | 3 个港口全部建设 `[1, 1, 1]` |
| **预计完成时间** | 2179 年（从 2050 起计 129 年） |
| **总成本估算** | $3.31 万亿美元 |
| **平均年运力** | 0.77 百万吨/年 |
| **前 10 年运力** | 纯火箭运输 30 万吨/年 |
| **电梯建成后运力** | 火箭 30 万 + 电梯 53.7 万 = 83.7 万吨/年 |

> 详细逐年调度数据见 [`t1_output.txt`](t1_output.txt)。

## 问题二：非完美工况下的鲁棒性优化

### 2.1 模型概述

在问题一确定性模型基础上，引入 **火箭发射故障**（伯努利概率 p=0.2）与 **太空电梯系绳摆动**（运力折减 θ=0.7）两类非完美工况，构建 **鲁棒性优化模型（Robust DT-MILP）**，并通过 **蒙特卡洛模拟** 验证全局可靠性。

- **核心方法**: SAA（样本平均近似）+ Benders 式分解 + 启发式调度规则提炼
- **验证机制**: 1000 次独立随机场景模拟，检验偏差率是否 ≤ 10%

### 2.2 关键假设

| 编号 | 假设内容 | 合理性说明 |
|------|----------|------------|
| 1 | 故障/摆动以离散时间步长为单位，单周期最多一次 | 符合 DT-MILP 框架，聚焦运力补偿核心逻辑 |
| 2 | 电梯摆动影响通过线性折减系数 θ 量化 | 安全阈值内近似线性，保证模型可解性 |
| 3 | 火箭故障为独立伯努利试验，概率静态 | 短期内故障概率无显著波动，符合工程实际 |
| 4 | 故障修复时间为单个时间步长 | 简化时间-运力耦合，后续可通过灵敏度分析验证 |
| 5 | 环境碳排放不受故障/摆动额外影响 | 分离运力补偿与环境维度，避免多目标耦合不可解 |

### 2.3 求解结果

#### 方案 A：基础鲁棒模型（`task2.py`）

| 指标 | 确定性基准 | 鲁棒优化（蒙特卡洛期望） |
|------|------------|--------------------------|
| **完成周期** | 126 | 138.6 ± 1.3 |
| **目标函数值** | 2.67×10³ | 2.66×10³ |
| **偏差率** | — | **0.45%** ✓（阈值 10%） |
| **运力缺口风险概率** | — | 0.0% |

> 故障导致平均周期延长 **12.6 年**，但额外故障成本占比为 0%，模型通过提前预留运力有效吸收了扰动。

#### 方案 B：SAA + 启发式调度（`task2_new.py`，推荐）

| 指标 | 数值 |
|------|------|
| **SAA 最优目标值** | 10.31 |
| **期望运力缺口** | 0.000 百万吨 |
| **期望抢修成本** | $3326 亿 |
| **电梯建设决策** | 3 个港口全部建设 `[1, 1, 1]` |
| **启发式评估期望完成周期** | 159.0 ± 0.16 |
| **缺口概率** | 0.000% |
| **期望总成本** | $8543 亿 |

> 启发式规则：电梯优先 + 火箭补足 + 追赶项（catch-up）+ 末期必达（required-rate）。

### 2.4 灵敏度与建议

- 当故障概率 **p > 0.3** 时，建议增加火箭基地冗余至 **12 个**
- 电梯摆动对总运力影响有限（θ=0.7），但需关注维护成本
- 惩罚系数 λ=1×10⁷ 有效保障了目标达成率

## 问题三：运营期水资源补给优化

### 3.1 模型概述

构建 **水资源动态补给优化模型（MILP）**，以“周”为决策周期，在 520 周（10 年）运营期内优化“运水 vs 运设备”的权衡决策。

- **核心创新**: 将“水循环设备运输”内化为“回收率动态提升”的反馈机制
- **状态方程**: 库存平衡 + 回收率演化 + 安全库存硬约束
- **目标**: 最小化总物流成本（等价于最小化火箭发射次数）

### 3.2 关键假设

| 编号 | 假设内容 | 合理性说明 |
|------|----------|------------|
| 1 | 决策周期为“周” | 火箭发射具有窗口期，按周决策捕捉需求波动又避免计算冗余 |
| 2 | 回收率提升与设备质量线性正相关，上限 99% | 工程应用阶段增加过滤设备通常线性增加处理能力 |
| 3 | 瞬时补给，忽略飞行时间 | Q3 关注长周期供需平衡，固定延迟可通过索引平移处理 |
| 4 | 10 万人需求为刚性值，极端缺水时允许削减舒适需求 | 符合灾难管理逻辑，增强模型鲁棒性 |

### 3.3 核心公式

- **Eq.(1) 目标函数**: `Min Z = Σ(C_launch · Cap · x_rocket,t)`
- **Eq.(2) 库存平衡**: `S_t = S_{t-1} + m_water,t + R_t – D_total,t`
- **Eq.(3) 循环再生**: `R_t = D_total,t-1 · η_{t-1}`
- **Eq.(4) 回收率演化**: `η_t = η_initial + α · Σm_equip,k`
- **Eq.(5) 回收率上限**: `η_t ≤ 0.99`
- **Eq.(6) 运力约束**: `m_water,t + m_equip,t ≤ x_rocket,t · Cap`
- **Eq.(8) 安全库存**: `S_t ≥ S_safe`

### 3.4 求解结果

| 指标 | 数值 |
|------|------|
| **规划总时长** | 520 周（10 年） |
| **初始大规模补给** | 第 0 周发射 1,405 枚火箭，运送 140,310 吨水 + 140 吨设备 |
| **稳态周补给** | 14 枚火箭/周，运送 1,400 吨水 |
| **稳态库存水平** | 810 吨（安全库存） |
| **最终回收率** | 99.0% |
| **自给自足率** | 99.0%（循环再生满足绝大部分需求） |
| **累计火箭发射** | 约 2,000+ 枚（10 年周期） |
| **累计成本** | 约 1,000 亿+ 美元 |

> 模型面临的核心权衡：现在运 100 吨水解渴（短期收益） vs 运 100 吨设备（长期收益，η 提升，未来需水量减少）。优化算法自动寻找到平衡点——初期大规模投建设备，后期仅靠少量火箭补充蒸发/泄漏损失。

## 问题四：评估并最小化环境影响

### 4.1 模型概述

设计 **两套互补方案** 评估并最小化地月物流的环境影响：

| 方案 | 名称 | 核心方法 | 定位 |
|------|------|----------|------|
| **方案 1** | 基础适配型 | MILP + 碳排放约束松弛 | 保分核心模型 |
| **方案 2** | 创新融合型 | 多目标整数规划 + AHP 阶段权重 + 遗传算法 | 冲奖关键模型 |

### 4.2 方案 1：MILP + 约束松弛

- **目标**: 最小化全周期总碳足迹 + 松弛惩罚
- **核心约束**: 总物资需求、基地/港口运力上限、碳排放上限（可松弛）
- **松弛机制**: 允许碳排放少量超额，通过惩罚系数 M 实现环境-进度权衡

#### 关键结果

| 指标 | 数值 |
|------|------|
| **规划周期** | 130 年 |
| **年均火箭发射** | 约 2000 枚（高峰期）/ 350–400 枚（调整期） |
| **年均电梯运输** | 约 53.7 万公吨 |
| **碳排放上限** | 从 18 万 tCO₂e/年 递增至 26 万 tCO₂e/年 |
| **松弛量** | 多数年份严格控制在 0，高峰期允许超额约 80 万 tCO₂e |
| **累计总运输** | 约 10,000 万公吨（满足目标） |

> 详细逐年数据见 [`t4_output/task4_basic_results.csv`](t4_output/task4_basic_results.csv)。

### 4.3 方案 2：多目标 + AHP + 遗传算法

- **三目标**: 环境最小化、成本最小化、时间最小化
- **AHP 阶段权重**: 基建期时间优先 → 运营期成本优先 → 稳定期环境优先
- **遗传算法**: 处理高维离散变量（基地启用 0-1 决策 + 发射数整数决策）
- **归一化**: 消除环境（tCO₂e）、成本（万美元）、时间（年）的量纲差异

#### Top 3 候选方案

| 方案类型 | 启用基地数 | 完成年份 | 总排放 (tCO₂e) | 总成本 (USD) | 综合适应度 |
|----------|------------|----------|----------------|--------------|------------|
| **环境优先 (env)** | 7 | 130 | 1.015×10⁸ | 2.10×10¹³ | 2.162 |
| **成本优先 (cost)** | 7 | 129 | 1.050×10⁸ | 2.09×10¹³ | 2.191 |
| **均衡方案 (balanced)** | 7 | 130 | 1.017×10⁸ | 2.10×10¹³ | 2.165 |

> 基地启用编码 `1110011011` 表示启用第 1,2,3,6,8,9,10 号基地（共 7 个）。

### 4.4 关键假设

| 编号 | 假设内容 | 合理性说明 |
|------|----------|------------|
| 1 | 决策周期按年离散划分 | 符合运力数据统计维度，降低求解复杂度 |
| 2 | 环境影响统一量化为碳足迹当量 | 国际通用指标，预处理已将多源排放转化 |
| 3 | 火箭/电梯排放系数为定值 | 载荷波动 ±10% 已在 Q2 覆盖，此处取均值 |
| 4 | 运力约束为硬约束，碳排放为可松弛硬约束 | 工程运力不可突破，环境政策允许少量超额 |
| 5 | 水资源需求为周期刚性值 | Q3 已完成稳态预测，此处纳入总量约束 |
